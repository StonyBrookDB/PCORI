=========================================================
Transformer — design notes
=========================================================
Defined in: src/seq_models.py — TransformerClassifier
Registered in: src/model_registry.py, factory _transformer()
Shared defaults: see note/_sequence_models_shared.txt

Architecture
------------
  Embedding(vocab_size, d_model=128, padding_idx=0)  +  sinusoidal positional encoding
  TransformerEncoder(
      layer = TransformerEncoderLayer(d_model=128, nhead=4,
                                      dim_feedforward=512,
                                      dropout=0.3, activation="gelu",
                                      batch_first=True, norm_first=True),
      num_layers = 2,
  )
  → PAD-aware mean pool over time
  → Dropout(0.3) → Linear(128 → 1) → sigmoid

Hyperparameters used:
  d_model            = 128
  num_heads          = 4
  num_layers         = 2
  dim_feedforward    = 4 * d_model = 512
  dropout            = 0.3
  positional encoding = sinusoidal (max_len=256)
  norm_first         = True (Pre-LN; trains more stably with bf16)
  activation         = gelu

Rationale
---------
- Standard pre-LN Transformer encoder. Pre-LN is preferred over post-LN
  for short-stack networks under mixed precision: no warmup needed,
  stable gradients on day 1, especially with bf16 autocast.
- Sinusoidal positional encoding (not learned) for two reasons:
    * sequence length is bounded (max_len=256) so we don't gain much
      from a learned table
    * sinusoidal generalizes to slightly different lengths if we later
      adjust max_len without re-training
- 2 encoder layers × 4 heads is intentionally small. Med-BERT and BEHRT
  found deeper models help on full unstructured EHR text but bring
  marginal gains on tokenized ICD-code sequences; we keep things lean.

Expected behavior
-----------------
- Per-fold training on top200: 2-5 min on RTX 5090 with bf16 + compile.
- The most parallel of the four sequence models — fully transformer-style
  forward/backward on the GPU.
- Expected AUROC: 0.84-0.88. Often within ~1% of Bi-LSTM on this kind of
  data, sometimes ahead, depending on regularization and the importance
  of position vs simple co-occurrence.

Caveats / future tuning
-----------------------
- num_layers=4 with the same width is the next thing to try if AUROC
  plateaus; cost roughly doubles.
- Could replace mean-pool with a CLS token (prepend a learned [CLS]
  embedding) for direct comparison with BERT-style classifiers.
- For full Transformer-style pretraining (MLM on patient sequences),
  we'd need a separate pretraining pipeline — out of scope for Phase 1.
