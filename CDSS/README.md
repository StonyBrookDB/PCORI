# CDSS — Clinical Decision Support System

Prototypes and supporting material for the Aim 2 interpretability / clinical
decision support component of the PCORI OUD project (patient-level risk
display, operating-point / decision-threshold tools, and related evaluation).

This folder is maintained separately from `SITL_Dashboard_PCORI/` (the
model-development and feature-review workbench) and from `model/` and
`feature_selection/`.

Content will be added incrementally around project milestones. No
patient-level data is stored here; all figures are aggregate or illustrative.
